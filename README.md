# DECISION LAB | مختبر القرار

تطبيق تفاعلي عربي باتجاه RTL للتدرب على مواقف عملية في التواصل والقيادة والتفكير والإدارة. يعمل محلياً باستخدام React وVite وTypeScript، ويحفظ تقدم التجارب في localStorage على الجهاز.

## المتطلبات

- Node.js 20 أو أحدث
- npm

## التشغيل

    npm install
    npm run dev

افتح عنوان Vite المحلي الذي يظهر في الطرفية.

## أوامر المشروع

    npm run build
    npm run lint
    npm test
    npm run preview

تشغّل `npm test` اختبارات السلوك باستخدام مشغّل Node المدمج، من دون إضافة اعتماد اختبار جديد.

صفحة لوحة النتائج تلخص عدد التجارب المكتملة والاختيارات ومؤشر التأمل للمسارات المجربة. هذه بيانات تفاعل محلية، وليست قياساً علمياً أو تقييماً نفسياً. يمكن مسح التقدم من إعدادات تخزين الموقع في المتصفح، تحت المفتاح decision-lab-progress-v1.
